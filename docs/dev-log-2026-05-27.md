# 开发记录 2026-05-27

## 1. 滚动条跳转修复

### 现象
点击编辑器中的 Markdown 链接 → 弹窗打开/关闭 → 编辑器内容滚动条重置到顶部。

### 排查过程

**第 1 次尝试 — memoize `editorProps`**
- 原因分析：TipTap v3 的 `useEditor` 每次渲染对比 options，`editorProps` 内联对象每次渲染创建新引用，触发 `setOptions` 导致 ProseMirror view 重置。
- 方案：`useMemo(() => ({...}), [])`
- 结果：❌ 未修复

**第 2 次尝试 — memoize extensions + mousedown 拦截**
- 原因分析：`StarterKit.configure({...})` 等 `.configure()` 每次渲染创建新实例，extensions 对比也失败。
- 方案：memoize 整个 `editorExtensions` 数组 + 添加 `mousedown` capture 拦截（阻止 ProSeMirror 在链接点击时设置光标并触发 `scrollSelectionIntoView`）。
- 结果：❌ 未修复

**第 3 次尝试 — 绝对定位 + useLayoutEffect 滚动保存恢复**
- 原因分析：WKWebView（macOS Tauri）中，flex 子元素 `overflow: auto` 在父级 flex 布局重算时会丢失滚动位置。弹窗打开时 body 样式变化 → flex 布局链重算 → scrollTop 归零。
- 方案：
  - 滚动容器从 `flex: 1` 改为 `position: absolute; inset: 0`
  - 保存滚动位置（mousedown 时），用 `useLayoutEffect` + `requestAnimationFrame` 恢复
  - 关闭弹窗的各路径（Update/Remove/Enter/X按钮）也保存恢复
- 结果：✅ 打开不再跳转，关闭仍跳转
- 补充：移除 `useLayoutEffect` 的 `linkDialogOpen &&` 条件，使其在开关弹窗时都恢复滚动

**第 4 次尝试 — `React.memo` 隔离滚动区域**
- 原因分析：弹窗状态在 `ChapterEditor` 内部，状态变化导致整个组件重新渲染，包括滚动容器。
- 方案：提取 `EditorArea` 组件，`React.memo` 包裹，只接收稳定 props（`editor`、`tocOpen`、`tocItems`、`scrollContainerRef`）。弹窗状态变化时，EditorArea props 不变 → 不重渲染 → 滚动位置自然保留。
- 结果：✅ 最终修复
- 额外保留：mousedown 拦截 + `dispatch(tr)` 时的 scroll 保存恢复（ProSeMirror 内部异步滚动仍需处理）

### 踩坑总结
- WKWebView 对 flex + overflow auto 的滚动处理不可靠，绝对定位是正确的隔离方式
- `React.memo` 是比 scroll save/restore 更根本的解决方案
- `useLayoutEffect` + `rAF` 双重恢复是为了对抗 ProSeMirror 的异步 `scrollSelectionIntoView`

## 2. 图片方案：Data URL → Tauri Asset Protocol

### 原因
Data URL 方案图片全量 base64 嵌入 DOM，100 张 1MB 图 → 约 130MB base64 在 DOM 中，内存压力大。

### 实施过程

**尝试 1 — 手动拼接 `https://asset.localhost/`**
```rust
format!("https://asset.localhost/{}", canonical.display())
```
- 问题 1：双斜杠 `//Users/...`
- 问题 2：`https` vs `http` 协议不对
- 结果：❌ 图片无法显示

**尝试 2 — `http://asset.localhost/` + trim 前导 `/`**
```rust
format!("http://asset.localhost/{}", canonical.to_string_lossy().trim_start_matches('/'))
```
- CSP 已有 `http://asset.localhost`
- 结果：❌ 图片无法显示

**尝试 3 — Tauri 官方 API `convertFileSrc`**
```rust
// Rust 只返回验证过的绝对路径
Ok(canonical.to_string_lossy().to_string())
```
```ts
// 前端用 convertFileSrc 转换
return convertFileSrc(absolutePath)
```
- 结果：✅ 图片正常显示

### 踩坑总结
- Tauri asset protocol URL 必须通过 `convertFileSrc()` 生成，不能手动拼接
- 正确格式：`asset://localhost/%2FUsers%2F...`（URL 编码，`asset://` 协议）
- CSP 需要：`asset:` + `http://asset.localhost` + `https://asset.localhost`
- Scope 需要：`$HOME/**/*`（注意 `**/*`），`requireLiteralLeadingDot: false`

## 5. 冲突解决功能

### 实现
- **Rust `git_resolve_conflict`**：遍历 git2 Index 查找 stage 2 (ours) / stage 3 (theirs)，读取 blob → 写入工作目录 → `index.add_path` 清除冲突标记
- **Rust `git_attempt_merge`**：fetch → `merge_commits` → 无冲突自动 commit → 有冲突返回文件列表
- **前端**：Conflict Panel（Keep Remote / Keep Local / Commit Merge）

### 踩坑：git2 0.19 API
- `IndexEntry` 字段和方法的区别：
  - git2 0.19：`entry.flags`（字段）、`entry.path`（字段）、`entry.id`（字段）
  - git2 0.20+：`.flags()`（方法）、`.path()`（方法）、`.id()`（方法）
- Stage 信息从 `flags` 提取：`let stage = (entry.flags >> 12) & 3`
- `conflict_get()` 方法在 0.19 中不存在，用 `iter()` 手动过滤

### 踩坑：IPC 阻塞
- `attempt_merge` 初始是同步命令，`git_fetch` 阻塞 IPC 线程 → 后续 Load 等操作排队卡死
- 修复：改为 `run_git_and_emit` 后台线程模式，Merge 按钮点后立即返回 "started"，结果通过 `git:done` 事件异步通知
- Merge 进入 loading 状态（spinner），类似 Fetch/Pull/Push

### 踩坑：按钮丢失
- 修改 JSX 时意外覆盖了 Fetch/Pull/Push 按钮，只剩 Merge 按钮
- 原因：替换设置弹窗区域时，把 Remote URL 输入区 + Fetch/Pull/Push 按钮整段覆盖了
- 修复：完整恢复四按钮布局（Fetch / Pull / Push / Merge）

## 6. 操作日志系统

### 实现
- **`logger.rs`**：`log_event(app, event, detail)` 追加 JSON 行到 `~/Library/Caches/com.gtbook.app/events.log`
- 格式：`{"t":"ISO8601","e":"event_type","d":"detail","b":"book_path_optional"}`
- **`run_git_and_emit`** 自动记录所有 git 异步操作（started/ok/failed/timed out/crashed）
- 非 book 事件（`set_books_dir`、`set_global_git_user`、`set_proxy_setting`）不带 `b` 字段

### 按书过滤
- `readBookLogs(limit, bookPath)` 按 `b` 字段过滤
- `readLogs(limit)` 返回全部日志

### 前端展示
- 详情页 Settings → Log tab：显示当前书的日志
- 书架页 BookCover 弹窗 → Log tab：显示该书的日志
- 书架页全局 Settings → Activity Log：显示所有 App 日志

## 7. 统一设置弹窗

### 设计
创建 `BookSettingsDialog` 组件，三个 Tab：Info / Git / Log

| Tab | 内容 |
|---|---|
| Info | 书名、路径、Reveal in Finder、更新时间、重命名、删除 |
| Git | Ahead/Behind 指示器、Git Changes、Commit、Remote URL、Fetch/Pull/Push/Merge、冲突解决面板 |
