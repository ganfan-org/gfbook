# 开发记录 2026-05-29

## 1. 全文搜索

### 架构
```
用户输入 → 防抖 300ms → invoke('start_search', { bookPaths, query })
                          ↓ 返回 "started"
                          ↓ 后台线程遍历所有书的 chapters/*.md + 章节标题
                          ↓ 每搜完一章 emit('search:progress', { book_path, book_title, chapter_id, chapter_title, matches })
                          ↓ 全部完成 emit('search:done')
```

### 后端
- `models.rs`：新增 `SearchLine` 结构体 + `flatten_chapters()` 函数（递归展开章节树）
- `commands.rs`：新增 `start_search` 命令，后台线程逐章扫描，case-insensitive 匹配
  - 先匹配章节标题（`line: 0`）
  - 再匹配正文内容（`line: 实际行号`）
- `lib.rs`：注册 `start_search`

### 前端
- `commands.ts`：新增 `startSearch()` + `SearchMatch` / `SearchProgressEvent` 接口
- `SearchDialog.tsx`：独立搜索弹窗组件
  - 输入防抖 300ms
  - 监听 `search:progress` 增量追加结果
  - 点击结果 → 关闭弹窗 → 导航到对应书/章节
  - 关闭时清理事件监听器

### 集成
| 页面 | 入口 | `bookPaths` | 点击行为 |
|---|---|---|---|
| BookShelf | 顶部搜索图标 | 所有书 | `onOpenBook(book, chapterId)` |
| BookDetail | 侧边栏搜索图标 | 当前书 | `selectChapter(chapterId)` |

### 数据流：搜索跳转到章节
```
搜索点击 → onSelectChapter(bookPath, chapterId)
  → BookShelf: 找到 book → onOpenBook(book, chapterId)
    → App: setCurrentBook + setPendingChapterId(chapterId)
      → BookDetail: initialChapterId → useEffect → selectChapter
```

### 踩坑
- **事件监听器清理**：每次搜索需前次清理 `cleanupRef.current?.()`，否则旧监听器仍收到事件，用 `searchIdRef` 比较过滤
- **autoFocus 不工作**：在动态渲染的弹窗中，`<input autoFocus>` 在 WKWebView 中不生效。使用 MUI Dialog 的 `slotProps.transition.onEntered` 回调聚焦

## 2. 项目重命名 gtbook → gfbook

全局搜索替换所有 `gtbook` 引用：

| 位置 | 旧值 | 新值 |
|---|---|---|
| `Cargo.toml` | `tauri-app` / `tauri_app_lib` | `gfbook` / `gfbook_lib` |
| `main.rs` | `tauri_app_lib::run()` | `gfbook_lib::run()` |
| `tauri.conf.json` | `GTBook` / `com.gtbook.app` | `gfbook` / `com.gfbook.app` |
| `package.json` | `tauri-app` | `gfbook` |
| `commands.rs` | `gtbook.yaml` / `gtbook-config.json` / `gtbooks` | `gfbook.yaml` / `gfbook-config.json` / `gfbooks` |
| `ChapterEditor.css` | `.gtbook-editor` (全部 20+ 处) | `.gfbook-editor` |
| `ChapterEditor.tsx` | `class: 'gtbook-editor'` | `class: 'gfbook-editor'` |
| `App.tsx` | `gtbook-theme` (localStorage) | `gfbook-theme` |
| `commands.rs:361` | 错误消息 `gtbook.yaml` | `gfbook.yaml` |

### 踩坑
- `edit` 工具不支持 `replaceAll`，CSS 中 20+ 处 `.gtbook-editor` 需用 `sed` 或手动逐个替换
- `gen/` 目录是 Tauri 生成的 schema 文件，引用 `tauri-apps/tauri` 是 GitHub 组织名，不应修改
- 改名后需 `cargo clean` 避免缓存冲突
